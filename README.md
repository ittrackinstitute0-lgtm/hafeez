# 📚 KitabGhar (کتاب گھر) - Online Book Store & Admin Portal

ایک مکمل اور جدید آن لائن بک اسٹور ویب سائٹ جس پر کسٹمرز کتابیں دیکھ سکتے ہیں، سرچ کر سکتے ہیں اور براہ راست آن لائن کیش آن ڈلیوری (COD) یا آن لائن پیمنٹ سے آرڈر کر سکتے ہیں۔ اس میں مکمل **Admin Panel** بھی شامل ہے اور یہ **Supabase Backend** کے ساتھ منسلک ہے۔

---

## 🌟 نمایاں خصوصیات (Key Features)

### 🛒 1. کسٹمر اسٹور فرنٹ (`index.html`)
- **خوبصورت کیٹلاگ:** اسلامی کتب، اردو ادب، سیلف ہیلپ، فنانس، فکشن وغیرہ۔
- **لائیو سرچ اور فلٹرز:** ٹائٹل، مصنف یا کیٹیگری کے ذریعے فوری سرچ۔
- **شارٹ لسٹ و کوئیک ویو (Quick View Modal):** کتاب کا خلاصہ، ریٹنگ اور تفصیلات۔
- **شاپنگ کارٹ (Shopping Cart Drawer):** کتابیں شامل کریں، مقدار تبدیل کریں، پرومو کوڈ (جیسے `KITAB10`) لگائیں۔
- **آرڈر چیک آؤٹ فارم (Checkout Form):** کسٹمر کا نام، واٹس ایپ فون نمبر، شہر اور مکمل پتہ۔
- **کیش آن ڈلیوری (COD) و دیگر پیمنٹس:** پاکستان بھر میں ڈلیوری۔
- **لائیو آرڈر ٹریکنگ (Live Order Tracking):** کسٹمر اپنا آرڈر آئی ڈی (جیسے `ORD-84920`) یا فون نمبر درج کر کے اپنے آرڈر کا لائیو اسٹیٹس چیک کر سکتا ہے (Order Placed ➔ Confirmed ➔ Dispatched ➔ Delivered)۔

### ⚙️ 2. ایڈمن پینل (`admin.html`)
- **سیکیورٹی پن لاک (PIN Protection):** ایڈمن لاگ ان ڈیفالٹ پن: `admin123` (سیٹنگز میں تبدیل ہو سکتا ہے)۔
- **ڈیش بورڈ کے اعدادوشمار (KPI Stats):** کل آمدنی (Revenue)، کل موصول شدہ آرڈرز، پینڈنگ آرڈرز اور کل کتابیں۔
- **آرڈرز مینجمنٹ (Orders Management):**
  - تمام کسٹمرز کے آرڈرز کی لائیو لسٹ۔
  - اسٹیٹس بدلیں: Pending, Confirmed, Processing, Shipped, Delivered, Cancelled۔
  - **انوائس و پرنٹنگ (Print Invoice):** 1-کلک سے کسٹمر کی مکمل انوائس پرنٹ کریں۔
  - آرڈر سرچ اور ڈیلیٹ آپشن۔
- **کتابوں کا انتظام (Books Inventory):**
  - نئی کتاب شامل کریں (نام، مصنف، قیمت، ڈسکاؤنٹ، کور تصویر، اسٹاک)۔
  - موجودہ کتاب کی قیمت یا معلومات تبدیل کریں (Edit Book)۔
  - کتاب ڈیلیٹ کریں۔
- **سپابیس ڈیٹابیس سیٹ اپ (Supabase Setup Tab):**
  - لائیو کنکشن اسٹیٹس چیکر۔
  - 1-کلک **"Copy Full SQL Script"** بٹن۔

### 🚀 ڈیٹابیس ٹیبلز کیسے بنائیں (صرف 2 منٹ کا کام):
1. اپنے براؤزر میں Supabase SQL Editor کھولیں:
   👉 **[Supabase SQL Editor](https://supabase.com/dashboard/project/gonheahzxpexxgaavsme/sql/new)**
2. پروجیکٹ میں موجود `schema.sql` فائل کا تمام کوڈ کاپی کریں (یا ایڈمن پینل کے `Supabase Setup` ٹیب پر جا کر **"Copy Full SQL Script"** بٹن دبائیں)۔
3. Supabase ایڈیٹر میں پیسٹ کریں اور نیچے دائیں جانب سبز رنگ کا **"Run"** بٹن دبا دیں۔
4. بس! ٹیبلز `books` اور `orders` خودکار طور پر تیار ہو جائیں گے اور نمونہ کتابیں بھی شامل ہو جائیں گی۔

> **نوٹ:** اگر آپ ابھی Supabase میں اسکرپٹ رن نہ بھی کریں، تب بھی ویب سائٹ خودکار طور پر **لوکل فال بیک موڈ (Local Fallback)** میں کام کرتی رہے گی، لہٰذا آپ فوراً ٹیسٹ کر سکتے ہیں۔
